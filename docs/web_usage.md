# Изменение данных на сайте

Обновление от 17 ноября 2026 года. Работает в прежнем учебном
проекте; изменения выполняются через ORM в текущей базе db.sqlite3.
Добавлена миграция matches/0002 для трех статусов. Вход для редактирования в локальной учебной
версии не требуется.

## Обновление и запуск

Если работаешь в другой копии проекта, распакуй новый архив и перенеси
файлы из его папки framework_pr1 поверх своей папки проекта с заменой.
Рабочий db.sqlite3 и окружение venv сохраняй: в архив они не включены.
Сервер перед заменой файлов останови сочетанием Ctrl+C.

В PowerShell в папке, где находится manage.py:

```powershell
.\venv\Scripts\python.exe manage.py runserver
```

Если окружение еще не создано:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe manage.py migrate
```

Только для новой пустой базы выполни импорт:

```powershell
.\venv\Scripts\python.exe manage.py import_pr7
```

На существующей базе повторять import_pr7 после редактирования не нужно:
он обновляет совпадающие ID исходными значениями.

## Статус и победитель

1. Открой http://127.0.0.1:8000/matches/ и нажми номер партии.
2. Под описанием есть блок «Изменить статус».
3. Выбери «Завершена», укажи победителя из участников и нажми
   «Сохранить статус».
4. Выбери «Будет идти» для запланированной партии или «Идет» для текущей.
   В обоих случаях победитель очищается; игра, участники, дата и длительность не меняются.

Данные сохраняются в базе; статус и статистика обновляются.
GET ничего не изменяет. Запись выполняется POST-запросом с CSRF-токеном
и перенаправлением после успешного сохранения.

## Редактирование и создание партий

В карточке нажми «Редактировать игру, участников, дату и длительность».
На этой странице можно также задать статус и победителя.
Победитель обязан входить в выбранный состав; количество участников
должно подходить для выбранной игры; длительность должна быть больше нуля.
Ошибки отображаются в форме, старые данные при ошибках сохраняются.
Для незавершенной партии поле победителя не сохраняется.

В списке партий кнопка «Добавить партию» открывает новую форму.
В списке участников ставь галочки рядом с нужными именами.

## Название игры

Открой «Игры», выбери игру, нажми «Редактировать игру».
Измени название, например «Уно» на «Дурак», и сохрани.
Это переименование существующей игры: ее ID и связанные партии сохраняются.

- games/templates/games/game_form.html — форма игры.
- tests/test_web_editing.py — проверки новых сценариев.
